Add =RgpotSurface::from_eam_table_file= and =RgpotSurface::from_eam_table_memory=, which construct an in-process =rgpot::EAMTablePot= from a DYNAMO table or from one-element tabulated arrays. Set =RGPOT_DIR= to the rgpot repository root or its =CppCore= directory, or run =ci/fetch_rgpot_cpp.sh=, which fetches the pin. When =RGPOT_DIR= is unset, the build uses that fetched tree when it is already at the pin, and otherwise reuses an existing cargo git checkout of the pin. =dr=, =drho= and =cutoff= must be finite and positive, knot values must be finite, and the bridge refuses an index =x*(1/step)+1= that does not fit in =int= before =EAMTablePot= is constructed. Evaluation refuses a summed density whose place index does not fit, instead of returning a wrong finite energy.
