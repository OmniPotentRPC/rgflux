Lammpc configuration updates and failed steps preserve the last accepted
Rust-side state. A failed step restores that state. The session is
recreated only when the step error is a lammpc backend error. Another
step error, including an unavailable backend, does not recreate the
session. Timesteps are compared relatively. =pair_style=, =pair_coeffs=,
=boundary= and =suffix= reject non-ASCII text, NULs, newlines, carriage
returns, and semicolons. =extra_setup= rejects a first token of =shell=,
=include=, =jump= or =python=.
