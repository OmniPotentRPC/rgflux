The PAFI dividing-plane search scales each derivative weight by the segment width before multiplying it by a plane mean, so the interpolant slopes no longer underflow to zero for a plane spacing near =1e155= or overflow for a spacing near =1e-150=, which had moved the dividing plane and the barrier or ended in an unrelated reactant-partition error. The segment endpoints use the integrated plane values, so the barrier is never below the highest sampled plane, and a slope or interior value that is not finite returns =FluxError::NonFinite= instead of dropping that segment from the search.
