=pafi::FreeEnergyProfile::reactant_partition=, =normalized_rate=, and =normalized_rate_error= changed type from =f64= to =Option<f64>=. Callers that read these fields must update and handle =None=. Each is derived from =reactant_log_partition=, =normalized_log_rate=, and the log-space delta-method error =ln(sigma_{ln k})= over the doubled-trapezoid reactant partition and the barrier. =reactant_partition= and =normalized_rate= are =None= when the linear exponential overflows or underflows =f64=. =normalized_rate_error= is =None= when it overflows and =Some(0.0)= when it underflows.
