=reactant_log_partition= and =normalized_log_rate= stay authoritative
for every finite value. Callers read =reactant_partition=,
=normalized_rate=, and =normalized_rate_error= as =Option<f64>=.
The public API now returns these linear fields as =Option<f64>=.
=reactant_partition= and =normalized_rate= are =None= when the
exponential of that finite log overflows or underflows.
=normalized_rate_error= holds
=exp(normalized_log_rate + ln(sigma_ln))= and is =None= only when that
value is not finite. A finite log stays on the profile.
