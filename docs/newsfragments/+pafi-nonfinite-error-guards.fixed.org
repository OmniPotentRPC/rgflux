A non-finite PAFI profile =standard_error= now returns =FluxError::NonFinite= instead of a profile with an infinite entry. The partial trapezoid sum behind the truncation term of =barrier_error= and =standard_error= rejects a NaN arc, no longer overflows for large gradients of opposite sign, and returns =FluxError::NonFinite= when its result is not finite. Results for ordinary input are unchanged to 1e-12.
