The value stored by default in =PafiConfig::zero_temperature_tol= is now about 2.6% instead of 1%. The zero-temperature check compares the path-force integral discrepancy with this dimensionless tolerance after dividing by the larger of one engine energy unit and the endpoint energy change magnitude. While the tolerance is not set, the effective tolerance scales as =2 (pi^2 / 12) / (planes - 1)^2=; a value passed to =with_zero_temperature_tol= is used exactly, even when it equals the default.
