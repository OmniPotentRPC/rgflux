The default =PafiConfig::zero_temperature_tol= is now about 2.6% instead of 1%. The zero-temperature check integrates the path force with the trapezoid rule, whose relative error on a quarter-turn circular arc through a harmonic well is =pi^2 / (12 (planes - 1)^2)=, or 1.29% at the default 9 planes, so the old default rejected that path. The new value is twice the 9-plane error. The field documentation states how the error scales with =planes= and when to raise the tolerance.
