* System prerequisites

- Current stable Rust with =clippy= and =rustfmt=.
- =jq= and =rustup= for minimum supported Rust version (=rust-version = "1.88"=) checks.
- Python 3.12+ and Emacs 29+ (=emacs-nox=) when building the Sphinx documentation from =docs/orgmode=.
- An installed =liblammpc= and its LAMMPS runtime when checking the =lammpc=
  feature or =--all-features=.

* Build and test

The default, =rgpot=, and =rgpot-session= feature sets need no external MD
library:

#+begin_src sh
cargo fmt --all -- --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
cargo clippy --locked --all-targets --features rgpot,rgpot-session -- -D warnings
cargo test --locked --features rgpot,rgpot-session
cargo test --locked --doc --features rgpot,rgpot-session
ci/check_rustdoc.sh
python3 ci/check_dependency_pins.py
python3 docs/check_paths.py
python3 ci/check_links.py
emacs --batch -l docs/export.el
sphinx-build -b linkcheck -n -W --keep-going docs/source target/docs-linkcheck
sphinx-build -b html -n -W --keep-going docs/source docs/build
#+end_src

The =rgpot= feature compiles rgpot's =EAMTablePot= for =RgpotSurface::from_eam_table_file= and =from_eam_table_memory=. Set =RGPOT_DIR= to the rgpot repository root or its =CppCore= directory, or run =ci/fetch_rgpot_cpp.sh=, which fetches the pin.

When =RGPOT_DIR= is unset, the build uses that fetched tree when it is already at the pin, and otherwise reuses an existing cargo git checkout of the pin.

Install =liblammpc= before enabling =lammpc=. Expose it through pkg-config,
=LAMMPC_DIR=, or =LAMMPC_LIB_DIR=, and include both =liblammpc= and LAMMPS on
the runtime loader path. Then =--features lammpc= or =--all-features= works:

#+begin_src sh
export LAMMPC_LIB_DIR=/path/to/lammpc/lib
export LD_LIBRARY_PATH="/path/to/lammpc/lib:/path/to/lammps/lib${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
cargo clippy --locked --all-targets --all-features -- -D warnings
cargo test --locked --all-features
cargo test --locked --doc --all-features
RUSTDOCFLAGS="-D warnings" cargo doc --locked --no-deps --all-features --document-private-items
#+end_src

* Dependency pins

=rgsaddle=, =rgmin=, and =rgpot-core= are required from crates.io with caret requirements (=version = "0.5.0"= and the matching requirements for the other two), so downstream builds can unify patch releases. =Cargo.lock= resolves them from crates.io, and the manifest has no git dependency and no =[patch.crates-io]= table. A git source that does appear must pin a full 40-hex commit =rev=, never a branch or tag name. =ci/check_dependency_pins.py= enforces those rules, checks that each locked version satisfies its requirement, and verifies that =Cargo.lock= and =cargo tree -d --features rgpot,rgpot-session= resolve a single copy of =rgflux=, =rgsaddle=, =rgmin=, =rgpot-core=, =eindir-core=, =dlpk=, =linkcell= and =minimage=. The =lammpc= feature is left out because it links =liblammpc=.
