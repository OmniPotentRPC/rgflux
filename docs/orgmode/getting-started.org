* Install

Add =rgflux= from crates.io (alongside =ndarray= and =rgsaddle= when defining custom potential surfaces) @@rst::cite:`goswamiEfficientExploration2025`@@:

#+begin_src console
$ cargo add rgflux
#+end_src

Enable optional =rgpot=, =rgpot-session=, and =lammpc= features as needed:

#+begin_src console
$ cargo add rgflux --features rgpot
$ cargo add rgflux --features rgpot-session
$ cargo add rgflux --features lammpc
#+end_src

The =lammpc= feature links =liblammpc= from =LAMMPC_LIB_DIR=, from =pkg-config= when available, or from =LAMMPC_DIR= (install prefix with =lib/= or =lib64/= and =include/=) when =pkg-config= is not configured. Include both =liblammpc= and its LAMMPS runtime on the loader path. Its build also needs the =capnp= command-line tool on =PATH=. =--all-features= therefore requires those libraries; builds with no features, or with =rgpot= or =rgpot-session=, do not.

* 1. Engine-free Bennett-Chandler recrossing

=kappa::bennett_chandler::estimate_bennett_chandler= estimates the time-dependent transmission coefficient \(\kappa(t)\) and its stationary plateau mean with a block-averaged standard error from =stats= @@rst::cite:`bennettMolecularDynamics1977,chandlerStatisticalMechanics1978,flegalMcmcThirdSignificantFigure2008`@@ directly from recorded dividing-surface velocity and side histories:

#+begin_src rust
use rgflux::kappa::bennett_chandler::{
    BennettChandlerConfig, ReactiveTrajectory, Side, estimate_bennett_chandler,
};

fn main() -> Result<(), rgflux::FluxError> {
    let trajectories = vec![
        ReactiveTrajectory::new(1.2, vec![Side::Product; 16])?,
        ReactiveTrajectory::new(-0.9, vec![Side::Reactant; 16])?,
        ReactiveTrajectory::new(0.8, vec![Side::Product; 16])?,
    ];
    let estimate = estimate_bennett_chandler(&trajectories, &BennettChandlerConfig::default())?;
    assert_eq!(estimate.plateau, 1.0);
    assert_eq!(estimate.standard_error, 0.0);
    assert!(estimate.stationarity.is_stationary);
    Ok(())
}
#+end_src

* 2. Climb the free energy of a dividing hyperplane (OH-TST)

Optimal hyperplanar transition state theory takes the dividing surface to be a hyperplane and moves it until its free energy is a maximum @@rst::cite:`johannessonOptimizationHyperplanar2001`@@. A converged dimer from =rgsaddle= seeds the plane, and =ohtst::PlaneOptimizer= climbs the plane free energy with short constrained Langevin samples. The surface is the skewed double well \(V = (x^2 - 1)^2 + \tfrac12 k(x)(y - x)^2\) with \(k(x) = 4(1 + 0.8 \tanh 2x)\), already in mass-weighted coordinates.

#+begin_src rust
use ndarray::{Array1, ArrayView1, array};
use rgflux::ohtst::{Hyperplane, LangevinConfig, PlaneOptimizer, PlaneOptimizerConfig};
use rgsaddle::{MinModeConfig, MinModeSession, MinModeStatus, PointSurface, SaddleError};

struct SkewedWell;

impl PointSurface for SkewedWell {
    fn eval(&self, q: ArrayView1<f64>) -> Result<(f64, Array1<f64>), SaddleError> {
        let (x, y) = (q[0], q[1]);
        let (well, tanh, valley) = (x * x - 1.0, (2.0 * x).tanh(), y - x);
        let k = 4.0 * (1.0 + 0.8 * tanh);
        let energy = well * well + 0.5 * k * valley * valley;
        let gx = 4.0 * x * well + 3.2 * (1.0 - tanh * tanh) * valley * valley - k * valley;
        Ok((energy, array![gx, k * valley]))
    }
}

fn main() -> Result<(), rgflux::FluxError> {
    let search = MinModeConfig::default().with_force_tol(1e-8);
    let mut dimer = MinModeSession::new(search, array![0.1, -0.05], array![1.0, 0.3])?;
    assert_eq!(dimer.run(&SkewedWell, 2000)?.status, MinModeStatus::Converged);
    let seed = Hyperplane::from_min_mode(&dimer)?.oriented_toward(array![1.0, 1.0].view());

    let sampler = LangevinConfig::default()
        .with_thermal(0.1)
        .with_time_step(0.1)
        .with_burn_in(200)
        .with_records(400)
        .with_seed(9);
    let config = PlaneOptimizerConfig::default()
        .with_sampler(sampler)
        .with_max_records(400)
        .with_max_iterations(10);
    let optimum = PlaneOptimizer::new(&seed, config)?.run(&SkewedWell)?;

    let normal = optimum.plane.normal();
    assert!((normal.dot(&normal) - 1.0).abs() < 1e-12);
    assert!(normal[0] > 0.0 && normal[1] > 0.0);
    Ok(())
}
#+end_src
