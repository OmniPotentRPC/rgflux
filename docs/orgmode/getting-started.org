#+TITLE: Getting started
#+OPTIONS: toc:nil num:nil

* Install

Add =rgflux= from the repository while initial kinetics modules migrate from =rgsaddle=:

#+begin_src console
$ cargo add --git https://github.com/OmniPotentRPC/rgflux --branch develop
#+end_src

Enable optional =rgpot= features as needed:

#+begin_src console
$ cargo check --features rgpot
$ cargo check --features rgpot-session
$ cargo check --features lammpc
#+end_src

The =lammpc= feature links =liblammpc= from pkg-config when available, from
=LAMMPC_DIR= (an install prefix with =lib/= or =lib64/=), or directly from
=LAMMPC_LIB_DIR=. Include both =liblammpc= and its LAMMPS runtime on the
loader path. =--all-features= therefore requires those libraries; builds with
no features or with =rgpot,rgpot-session= do not.

* Reactive-flux recrossing

=kappa::bennett_chandler= estimates the time-dependent transmission coefficient \(\kappa(t)\) and its plateau mean with a block-averaged standard error from =stats=, either from pre-recorded dividing-surface velocity and side histories or by shooting trajectories through any =DynamicsEngine= implementation such as =engine::native::NativeEngine=.
