* Install

Add =rgflux= from crates.io (alongside =ndarray= and =rgsaddle= when defining custom potential surfaces) @@rst::cite:`goswamiEfficientExploration2025`@@:

#+begin_src console
$ cargo add rgflux
#+end_src

Enable optional =rgpot=, =rgpot-session=, and =lammpc= features as needed:

#+begin_src console
$ cargo add rgflux --features rgpot
$ cargo add rgflux --features rgpot-session
$ cargo add rgflux --features lammpc
#+end_src

The =lammpc= feature links =liblammpc= from =LAMMPC_LIB_DIR=, from =pkg-config= when available, or from =LAMMPC_DIR= (install prefix with =lib/= or =lib64/= and =include/=) when =pkg-config= is not configured. Its build also needs the =capnp= command-line tool on =PATH=; the =rgpot= and =rgpot-session= features do not.

* 1. Engine-free Bennett-Chandler recrossing

=kappa::bennett_chandler::estimate_bennett_chandler= estimates the time-dependent transmission coefficient \(\kappa(t)\) and its stationary plateau mean with a block-averaged standard error from =stats= @@rst::cite:`bennettMolecularDynamics1977,chandlerStatisticalMechanics1978,flegalMcmcThirdSignificantFigure2008`@@ directly from recorded dividing-surface velocity and side histories:

#+begin_src rust
use rgflux::kappa::bennett_chandler::{
    BennettChandlerConfig, ReactiveTrajectory, Side, estimate_bennett_chandler,
};

fn main() -> Result<(), rgflux::FluxError> {
    let trajectories = vec![
        ReactiveTrajectory::new(1.2, vec![Side::Product; 16])?,
        ReactiveTrajectory::new(-0.9, vec![Side::Reactant; 16])?,
        ReactiveTrajectory::new(0.8, vec![Side::Product; 16])?,
    ];
    let estimate = estimate_bennett_chandler(&trajectories, &BennettChandlerConfig::default())?;
    assert_eq!(estimate.plateau, 1.0);
    assert_eq!(estimate.standard_error, 0.0);
    assert!(estimate.stationarity.is_stationary);
    Ok(())
}
#+end_src

* 2. Drive a surface with =NativeEngine= and evaluate an OH-TST rate

Implement =rgsaddle::PointSurface= (returning potential energy \(V(\mathbf{x})\) and gradient \(+\nabla V(\mathbf{x})\)), construct =engine::native::NativeEngine=, and call =ohtst::optimize_hyperplane= @@rst::cite:`johannessonOptimizationHyperplanar2001,vineyardFrequencyFactors1957`@@ to place the dividing hyperplane at the barrier top and evaluate the harmonic hyperplanar TST rate:

#+begin_src rust
use ndarray::{Array1, ArrayView1};
use rgflux::engine::native::{NativeConfig, NativeEngine};
use rgflux::engine::{DynamicsEngine, HyperplaneConstraint, ThermostatConfig};
use rgflux::ohtst::{OhtstConfig, optimize_hyperplane};

struct QuarticDoubleWell1D;

impl rgsaddle::PointSurface for QuarticDoubleWell1D {
    fn eval(&self, x: ArrayView1<f64>) -> Result<(f64, Array1<f64>), rgsaddle::SaddleError> {
        let u = x[0];
        let well = u * u - 1.0;
        Ok((0.25 * well * well, Array1::from_vec(vec![u * well])))
    }
}

fn main() -> Result<(), rgflux::FluxError> {
    let cfg = NativeConfig::default()
        .with_masses(Array1::from_vec(vec![1.0]))
        .with_thermostat(
            ThermostatConfig::default()
                .with_gamma(1.0)
                .with_temperature(0.1),
        )
        .with_seed(17);
    let mut engine = NativeEngine::new(QuarticDoubleWell1D, cfg)?;
    engine.set_positions(Array1::from_vec(vec![-1.0]).view())?;

    let seed_plane =
        HyperplaneConstraint::from_direction(Array1::from_vec(vec![1.0]).view(), 0.0)?;
    let ohtst_cfg = OhtstConfig::default()
        .with_burn_in_steps(64)
        .with_min_sample_steps(128)
        .with_sample_step_factor(4)
        .with_seed(17);
    let estimate = optimize_hyperplane(&mut engine, &seed_plane, &ohtst_cfg)?;

    assert_eq!(estimate.plane.offset, 0.0);
    assert!(estimate.rate > 0.0 && estimate.standard_error.is_finite());
    Ok(())
}
#+end_src
