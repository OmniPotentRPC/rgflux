#+TITLE: How-to guides
#+OPTIONS: toc:nil num:nil

* Run constrained Langevin dynamics on a hyperplane

Construct a =HyperplaneConstraint= from a unit normal \(\mathbf{n}\) and scalar offset \(c\), attach it to =NativeEngine=, and step with BAOAB + RATTLE. Each =StepReport= carries the holonomic Lagrange multiplier \(\lambda\), whose canonical mean equals \(dF/dc\) @@rst::cite:`sprikFreeEnergyConstrained1998,leimkuhlerGeodesicIntegration2016`@@.

* Estimate a Bennett-Chandler transmission coefficient

Pass recorded =ReactiveTrajectory= histories to =estimate_bennett_chandler= for engine-free analysis, or call =shoot_bennett_chandler= with a mutable =DynamicsEngine= and dividing-surface configurations to generate and reduce reactive-flux trajectories in one pass @@rst::cite:`bennettMolecularDynamics1977,chandlerStatisticalMechanics1978`@@.

* Evolve a finite-temperature string

Start with at least three path images. Build a =FiniteTemperatureStringConfig= from =Default=, then set its =sampling= field with a =HyperplaneConfig=. =finite_temperature_string= constructs the plane through each image, normal to the centered path tangent; runs constrained dynamics through =DynamicsEngine=; evolves interior images with the mean in-plane force; and redistributes them at equal arc length with =rgsaddle::reparametrize= @@rst::cite:`eFiniteTemperatureString2005,vandenEijndenRevisitingFiniteTemperature2009`@@.

#+begin_src rust
let sampling = HyperplaneConfig::default()
    .with_burn_in_steps(500)
    .with_sample_steps(4_000);
let config = FiniteTemperatureStringConfig::default()
    .with_sampling(sampling)
    .with_seed(17);
let result = finite_temperature_string(&mut engine, images.view(), &config)?;
#+end_src

The string-with-swarms entry point is =swarm_string=. Each image launches independently seeded constrained trajectories and moves by their mean sampled displacement before the same equal-arc redistribution @@rst::cite:`panFindingTransitionPathways2008`@@. Both entry points restore positions, velocities, thermostat, and the pre-existing constraint before returning. They do not snapshot or restore the simulation cell, so callers using an engine with evolving cell state must manage that state themselves.

* Use rgflux PAFI with an engine-agnostic path

=rgflux= owns rare-event estimators, including the =pafi= API; =rgsaddle= remains engine-agnostic and supplies reaction paths. The current =pafi_profile= entry point explicitly returns =Unimplemented= while the curvature/Jacobian estimator and profile quadrature are completed. Until then, obtain each path image and tangent from the path-search code, call =plane_from_path_image= and =sample_hyperplane= in =rgflux=, and retain the returned =mean_projected_force=, =mean_position=, =position_covariance=, raw normal =mean_force=, and configurations for the eventual PAFI calculation. The raw RATTLE multiplier is not the full PAFI estimator.
