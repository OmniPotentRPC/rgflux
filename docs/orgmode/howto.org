* Sample holonomic hyperplane mean forces and configurations

Construct a =HyperplaneConstraint= from a direction vector and scalar offset \(c\), configure =HyperplaneConfig=, and call =hyperplane::sample_hyperplane= over any =DynamicsEngine= @@rst::cite:`sprikFreeEnergyConstrained1998,leimkuhlerGeodesicIntegration2016`@@. =sample_hyperplane= installs the constraint, runs BAOAB + RATTLE equilibration and production steps, estimates \(\langle \lambda \rangle = dA/dc\) with a block-averaged standard error, retains dividing-surface configurations every =retention_stride= steps, and restores the engine's initial positions, velocities, periodic cell, thermostat, and constraint before returning:

#+begin_src rust
use ndarray::{Array1, ArrayView1};
use rgflux::engine::native::{NativeConfig, NativeEngine};
use rgflux::engine::{DynamicsEngine, HyperplaneConstraint, ThermostatConfig};
use rgflux::hyperplane::{HyperplaneConfig, sample_hyperplane};

struct DoubleWell2D;

impl rgsaddle::PointSurface for DoubleWell2D {
    fn eval(&self, r: ArrayView1<f64>) -> Result<(f64, Array1<f64>), rgsaddle::SaddleError> {
        let (x, y) = (r[0], r[1]);
        let well = x * x - 1.0;
        Ok((
            0.25 * well * well + 0.5 * y * y,
            Array1::from_vec(vec![x * well, y]),
        ))
    }
}

fn main() -> Result<(), rgflux::FluxError> {
    let mut engine = NativeEngine::new(
        DoubleWell2D,
        NativeConfig::default()
            .with_masses(Array1::from_vec(vec![1.0, 1.0]))
            .with_thermostat(
                ThermostatConfig::default()
                    .with_gamma(1.0)
                    .with_temperature(0.2),
            )
            .with_seed(11),
    )?;
    engine.set_positions(Array1::from_vec(vec![-0.3, 0.0]).view())?;

    let plane =
        HyperplaneConstraint::from_direction(Array1::from_vec(vec![1.0, 0.0]).view(), -0.3)?;
    let cfg = HyperplaneConfig::default()
        .with_burn_in_steps(100)
        .with_sample_steps(400)
        .with_retention_stride(20)
        .with_time_step(0.01)
        .with_seed(11);

    let sample = sample_hyperplane(&mut engine, &plane, &cfg)?;
    assert!(sample.mean_force.is_finite());
    assert!(sample.standard_error >= 0.0);
    assert_eq!(sample.configurations.dim(), (20, 2));
    assert!(engine.constraint().is_none());
    Ok(())
}
#+end_src

* Diagnose correlated samples with batch means, effective sample size, and Geweke windows

Use =stats::batch_means= for the mean and its correlation-aware standard
error, =stats::effective_sample_size= for the Geyer initial monotone sequence
estimate, and =stats::check_stationarity= before accepting an equilibrium or
plateau window
@@rst::cite:`goswamiBayesianHierarchical2025,flyvbjergErrorEstimates1989,geyerPracticalMcmc1992,gewekeEvaluatingAccuracy1992,flegalMcmcThirdSignificantFigure2008`@@.

For \(a\) non-overlapping batches of width \(b\), batch means \(Y_j\), and
\(n = ab\) retained observations, the asymptotic variance and standard error
are

\[
 \widehat{\sigma}_{\mathrm{BM}}^2 =
 \frac{b}{a - 1}\sum_{j=1}^{a}(Y_j-\bar{Y})^2,\qquad
 \operatorname{SE}(\bar{X}) =
 \sqrt{\widehat{\sigma}_{\mathrm{BM}}^2/n}.
\]

Geyer's paired initial positive and monotone autocovariance sequence gives the
statistical inefficiency \(g = 2\tau_{\mathrm{int}}\) and
\(n_{\mathrm{eff}} = n/g\). The Geweke diagnostic compares leading and
trailing windows with

\[
 \lvert z\rvert =
 \frac{|\bar{X}_{\mathrm{first}}-\bar{X}_{\mathrm{last}}|}
 {\sqrt{\operatorname{SE}_{\mathrm{first}}^2+
        \operatorname{SE}_{\mathrm{last}}^2}}.
\]

#+begin_src rust
use rgflux::stats::{
    StatsConfig, batch_means, check_stationarity, effective_sample_size,
};

fn main() -> Result<(), rgflux::FluxError> {
    let samples: Vec<f64> = (0..256)
        .map(|i| {
            let phase = (i % 16) as f64;
            (phase * std::f64::consts::TAU / 16.0).sin()
        })
        .collect();
    let config = StatsConfig::default()
        .with_min_batches(8)
        .with_stationarity_first_fraction(0.25)
        .with_stationarity_last_fraction(0.50)
        .with_max_z_score(3.0);

    let estimate = batch_means(&samples, &config)?;
    let n_eff = effective_sample_size(&samples)?;
    let stationarity = check_stationarity(&samples, &config)?;

    assert!(estimate.standard_error >= 0.0);
    assert_eq!(estimate.n_eff, n_eff);
    assert!(n_eff >= 1.0 && n_eff <= samples.len() as f64);
    assert!(stationarity.is_stationary);
    Ok(())
}
#+end_src

* Assemble a rate-network edge and kMC configuration

A directed rate network stores non-negative first-order rates \(k_{ij}\).
Its continuous-time master equation is

\[
 \frac{dp_i}{dt} =
 \sum_{j\ne i} p_j k_{ji} -
 p_i\sum_{j\ne i}k_{ij}.
\]
For a BKL or Gillespie residence-time step in state \(i\), define
\(K_i = \sum_j k_{ij}\), select event \(j\) with probability
\(k_{ij}/K_i\), and draw
\(\Delta t = -\ln u/K_i\) for \(u\) uniform on \((0,1)\)
@@rst::cite:`goswamiEfficientExploration2025,goswamiConcurrencyAkmc2025,bortzNewAlgorithmMonteCarlo1975,gillespieGeneralMethod1976,henkelmanLongTimeScale2001`@@.

=RateEdge::new= validates one directed edge. =NetworkConfig= records thermal
and detailed-balance policy, while =RateTableConfig= records trajectory
limits. =build_rate_table= is deliberately a typed migration boundary in this
release and returns =FluxError::Unimplemented= rather than silently producing
an incomplete table.

#+begin_src rust
use rgflux::FluxError;
use rgflux::network::{
    NetworkConfig, RateEdge, RateTableConfig, build_rate_table,
};

fn main() -> Result<(), rgflux::FluxError> {
    let edges = vec![
        RateEdge::new(0, 1, 2.0)?,
        RateEdge::new(1, 0, 0.5)?,
    ];
    let network = NetworkConfig::default()
        .with_temperature(500.0)
        .with_boltzmann(1.0)
        .with_enforce_detailed_balance(true)
        .with_min_rate(1.0e-12);
    let trajectory = RateTableConfig::default()
        .with_max_steps(10_000)
        .with_seed(7);

    assert_eq!(trajectory.max_steps, 10_000);
    assert!(matches!(
        build_rate_table(2, &edges, &network),
        Err(FluxError::Unimplemented(_))
    ));
    Ok(())
}
#+end_src

* Place a fixed-normal OH-TST dividing hyperplane and evaluate the rate

Pass a seed =HyperplaneConstraint= and =OhtstConfig= to =ohtst::optimize_hyperplane= @@rst::cite:`goswamiAdaptivePruning2026,johannessonOptimizationHyperplanar2001,bligaardOptimizationHyperplanar2005,vineyardFrequencyFactors1957`@@. Even when the seed offset is displaced from the saddle (here \(c_0 = -0.4\) while the barrier sits at \(c^\ddagger = 0\)), =optimize_hyperplane= relaxes into the reactant minimum, brackets and bisects the stationary dividing hyperplane along the seed normal, samples the curvature probe plane, and returns \(k_{\mathrm{OHTST}} = \frac{1}{2\pi}\sqrt{\kappa / \mu}\exp(-\Delta V / k_{\mathrm{B}}T)\) (with \(\mu\) from =rgsaddle::flux_mass=) alongside its delta-method standard error. The probe average is canonical, so the engine needs a supported canonical thermostat. White noise requires \(\gamma > 0\); its \(\gamma = 0\) mode is NVE and =optimize_hyperplane= returns =FluxError::InvalidConfig= before the search. A supported colored-noise thermostat can use \(\gamma = 0\):

#+begin_src rust
use ndarray::{Array1, ArrayView1};
use rgflux::engine::native::{NativeConfig, NativeEngine};
use rgflux::engine::{DynamicsEngine, HyperplaneConstraint, ThermostatConfig};
use rgflux::ohtst::{OhtstConfig, optimize_hyperplane};

struct ObliqueDoubleWell2D;

impl rgsaddle::PointSurface for ObliqueDoubleWell2D {
    fn eval(&self, r: ArrayView1<f64>) -> Result<(f64, Array1<f64>), rgsaddle::SaddleError> {
        let u = 0.6 * r[0] + 0.8 * r[1];
        let v = -0.8 * r[0] + 0.6 * r[1];
        let well = u * u - 1.0;
        let du = u * well;
        let dv = 2.0 * v;
        Ok((
            0.25 * well * well + v * v,
            Array1::from_vec(vec![0.6 * du - 0.8 * dv, 0.8 * du + 0.6 * dv]),
        ))
    }
}

fn main() -> Result<(), rgflux::FluxError> {
    let mut engine = NativeEngine::new(
        ObliqueDoubleWell2D,
        NativeConfig::default()
            .with_masses(Array1::from_vec(vec![2.0, 8.0]))
            .with_thermostat(
                ThermostatConfig::default()
                    .with_gamma(1.0)
                    .with_temperature(0.1),
            )
            .with_seed(33),
    )?;
    engine.set_positions(Array1::from_vec(vec![-0.6, -0.8]).view())?;

    // Seed normal (3, 4) / 5 = (0.6, 0.8) with a displaced offset c_0 = -0.4.
    let seed_plane =
        HyperplaneConstraint::from_direction(Array1::from_vec(vec![3.0, 4.0]).view(), -0.4)?;
    let cfg = OhtstConfig::default()
        .with_max_outer_steps(16)
        .with_max_translation(0.25)
        .with_burn_in_steps(64)
        .with_min_sample_steps(128)
        .with_sample_step_factor(8)
        .with_time_step(0.01)
        .with_seed(33);

    let est = optimize_hyperplane(&mut engine, &seed_plane, &cfg)?;
    assert!(est.plane.offset.abs() < 1e-12);
    assert!(est.rate > 0.0 && est.standard_error.is_finite());
    Ok(())
}
#+end_src

** Relax a reactant once and evaluate every exit

The reactant is a minimum once its largest force component \(\max_i \lvert F_i \rvert\) is at most =OhtstConfig::reactant_fmax= (default \(10^{-6}\) in the engine force unit, eV/Å in metal units). =ohtst::relax_reactant= relaxes the engine's positions with =rgmin::Lbfgs= to that tolerance, restores the engine, and returns a =ReactantMinimum= holding the coordinates and the measured force. =ohtst::optimize_hyperplane_from_minimum= takes that minimum, or one relaxed by another code, and evaluates one exit without relaxing again, so a basin with several exits is relaxed once. A supplied minimum is refused with =FluxError::ReactantNotRelaxed= when its declared force or the force the engine measures there exceeds =reactant_fmax=; there is no fallback rate:

#+begin_src rust
use ndarray::{Array1, ArrayView1};
use rgflux::engine::native::{NativeConfig, NativeEngine};
use rgflux::engine::{DynamicsEngine, HyperplaneConstraint, ThermostatConfig};
use rgflux::ohtst::{
    OhtstConfig, ReactantMinimum, optimize_hyperplane_from_minimum, relax_reactant,
};

// Independent double wells along x and y: the reactant at (-1, -1) has one
// exit over each barrier.
struct TwoExitWell;

impl rgsaddle::PointSurface for TwoExitWell {
    fn eval(&self, r: ArrayView1<f64>) -> Result<(f64, Array1<f64>), rgsaddle::SaddleError> {
        let (wx, wy) = (r[0] * r[0] - 1.0, r[1] * r[1] - 1.0);
        Ok((
            0.25 * (wx * wx + wy * wy),
            Array1::from_vec(vec![r[0] * wx, r[1] * wy]),
        ))
    }
}

fn main() -> Result<(), rgflux::FluxError> {
    let mut engine = NativeEngine::new(
        TwoExitWell,
        NativeConfig::default()
            .with_masses(Array1::from_vec(vec![1.0, 1.0]))
            .with_thermostat(
                ThermostatConfig::default()
                    .with_gamma(1.0)
                    .with_temperature(0.1),
            )
            .with_seed(7),
    )?;
    engine.set_positions(Array1::from_vec(vec![-0.8, -1.3]).view())?;
    let cfg = OhtstConfig::default()
        .with_reactant_fmax(1e-8)
        .with_burn_in_steps(64)
        .with_min_sample_steps(128)
        .with_sample_step_factor(8)
        .with_seed(7);

    let reactant = relax_reactant(&mut engine, &cfg)?;
    assert!(reactant.fmax <= 1e-8);
    for direction in [[1.0, 0.0], [0.0, 1.0]] {
        let exit =
            HyperplaneConstraint::from_direction(Array1::from_vec(direction.to_vec()).view(), 0.0)?;
        let est = optimize_hyperplane_from_minimum(&mut engine, &exit, &reactant, &cfg)?;
        assert!(est.rate > 0.0 && est.standard_error.is_finite());
    }

    // A minimum relaxed elsewhere, with the force measured there.
    let exit = HyperplaneConstraint::from_direction(Array1::from_vec(vec![1.0, 0.0]).view(), 0.0)?;
    let external = ReactantMinimum::new(Array1::from_vec(vec![-1.0, -1.0]), 0.0);
    assert!(optimize_hyperplane_from_minimum(&mut engine, &exit, &external, &cfg).is_ok());
    let loose = ReactantMinimum::new(Array1::from_vec(vec![-1.0, -1.0]), 1e-3);
    assert!(matches!(
        optimize_hyperplane_from_minimum(&mut engine, &exit, &loose, &cfg),
        Err(rgflux::FluxError::ReactantNotRelaxed { .. })
    ));
    Ok(())
}
#+end_src

* Compute a transition rate with direct Forward Flux Sampling (FFS)

Initialize the engine inside reactant basin \(A\) (\(\lambda(\mathbf{x}_0) \le \lambda_0\)) with positive Langevin friction \(\gamma > 0\), specify strictly increasing interfaces \(\lambda_0 < \lambda_1 < \dots < \lambda_n\) in =FfsConfig=, and pass an order-parameter closure \(\lambda(\mathbf{x})\) to =ffs::forward_flux_rate= @@rst::cite:`goswamiEfficientExploration2025,allenSamplingRareSwitching2005,allenSimulatingRareEvents2006,allenForwardFluxEfficiency2006,allenForwardFluxReview2009`@@:

#+begin_src rust
use ndarray::{Array1, ArrayView1};
use rgflux::engine::native::{NativeConfig, NativeEngine};
use rgflux::engine::{DynamicsEngine, ThermostatConfig};
use rgflux::ffs::{FfsConfig, forward_flux_rate};

struct QuarticDoubleWell1D;

impl rgsaddle::PointSurface for QuarticDoubleWell1D {
    fn eval(&self, x: ArrayView1<f64>) -> Result<(f64, Array1<f64>), rgsaddle::SaddleError> {
        let dx = x[0] * x[0] - 1.0;
        Ok((dx * dx, Array1::from_vec(vec![4.0 * x[0] * dx])))
    }
}

fn main() -> Result<(), rgflux::FluxError> {
    let cfg = NativeConfig::default()
        .with_masses(Array1::from_vec(vec![1.0]))
        .with_thermostat(
            ThermostatConfig::default()
                .with_gamma(2.0)
                .with_temperature(0.9),
        )
        .with_seed(11);
    let mut engine = NativeEngine::new(QuarticDoubleWell1D, cfg)?;
    engine.set_positions(Array1::from_vec(vec![-1.0]).view())?;
    engine.shoot_velocities(11)?;

    let ffs_cfg = FfsConfig::default()
        .with_interfaces(vec![-0.8, -0.4, -0.1, 0.2])
        .with_points_per_interface(16)
        .with_trials_per_interface(64)
        .with_max_trial_steps(3_000)
        .with_max_flux_steps(400_000)
        .with_burn_in_steps(50)
        .with_time_step(0.01)
        .with_seed(11);

    let est = forward_flux_rate(&mut engine, |x| x[0], &ffs_cfg)?;
    assert!(est.initial_flux > 0.0);
    assert_eq!(est.interface_probabilities.len(), 3);
    assert!(est.rate > 0.0 && est.standard_error > 0.0);
    assert_eq!(engine.positions()[0], -1.0);
    Ok(())
}
#+end_src

* Compute a free-energy profile, barrier and rate along a reaction path (PAFI workflow)

Projected Average Force Integration (PAFI) @@rst::cite:`goswamiEnhancedClimbingImage2026,goswamiReproducibleOrchestration2026,swinburneUnsupervisedCalculation2018`@@ takes the images of a converged minimum-energy path, for example from a nudged elastic band, and returns the free-energy profile \(F(s)\), the barrier \(\Delta F\), the dividing plane, and the normalized rate \(k\) through =pafi::pafi_profile=. The method is described under /Projected Average Force Integration/ in the explanation page and the defaults in the reference page.

The example runs a straight path from the minimum \(x = -1\) to the saddle \(x = 0\) of the widening double well \(V(x, y) = (1 - x^2)^2 + \tfrac{1}{2}(1.5 + 0.5x)y^2\) at \(k_{\mathrm{B}}T = 0.2\), where the exact barrier is \(\Delta F = 1 + \tfrac{1}{2}k_{\mathrm{B}}T \ln 1.5\). It uses 33 planes. The free-energy profile is the cubic Hermite integral of the plane means, so the trapezoid bias of about \(0.0156\,(8/(\text{planes} - 1))^2\) (0.025 with the default 9 planes, 0.0016 with 33) is the scale of the zero-temperature guard and is not left in \(\Delta F\). The run checks the barrier within five standard errors.

#+begin_src rust
use ndarray::{Array1, Array2, ArrayView1};
use rgflux::engine::ThermostatConfig;
use rgflux::engine::native::{NativeConfig, NativeEngine};
use rgflux::pafi::{PafiConfig, pafi_profile};
use rgflux::stats::StatsConfig;

struct WideningWell2D;

impl rgsaddle::PointSurface for WideningWell2D {
    fn eval(&self, r: ArrayView1<f64>) -> Result<(f64, Array1<f64>), rgsaddle::SaddleError> {
        let (x, y) = (r[0], r[1]);
        let well = 1.0 - x * x;
        let k = 1.5 + 0.5 * x;
        Ok((
            well * well + 0.5 * k * y * y,
            Array1::from_vec(vec![-4.0 * x * well + 0.25 * y * y, k * y]),
        ))
    }
}

fn main() -> Result<(), rgflux::FluxError> {
    let temperature = 0.2;
    let mut engine = NativeEngine::new(
        WideningWell2D,
        NativeConfig::default()
            .with_masses(Array1::from_vec(vec![1.0, 1.0]))
            .with_thermostat(
                ThermostatConfig::default()
                    .with_gamma(1.5)
                    .with_temperature(temperature),
            )
            .with_seed(19),
    )?;

    // PAFI samples at `config.planes` planes along a spline through these
    // images. Two images would do for a straight path; a curved path needs
    // the images of the converged band.
    let config = PafiConfig::default()
        .with_planes(33)
        .with_burn_in_steps(500)
        .with_sample_steps(8_000)
        .with_stats(StatsConfig::default().with_min_batches(4))
        .with_seed(19);
    let images = 5;
    let mut path = Array2::<f64>::zeros((images, 2));
    for k in 0..images {
        path[[k, 0]] = -1.0 + (k as f64) / ((images - 1) as f64);
    }

    let profile = pafi_profile(&mut engine, path.view(), &config)?;
    assert_eq!(profile.arc_lengths.len(), config.planes);
    assert_eq!(profile.free_energy[0], 0.0);
    assert_eq!(profile.dividing_index, config.planes - 1);

    let analytic = 1.0 + 0.5 * temperature * 1.5_f64.ln();
    assert!(profile.barrier_error > 0.0);
    assert!((profile.barrier - analytic).abs() < 5.0 * profile.barrier_error);
    assert!(
        profile.normalized_rate.is_some_and(|rate| rate > 0.0)
            && profile
                .normalized_rate_error
                .is_some_and(|error| error > 0.0)
    );
    Ok(())
}
#+end_src

Points to adapt for a real path:

- *Images*: =path_images= has one row per image and one column per degree of freedom, in the units and ordering of the engine. The planes are placed by the spline, not at the images, so the number of images and =planes= are independent.
- *Planes and tolerance*: The zero-temperature check compares \(\lvert I_T - \Delta E_0\rvert / \max(E_{\mathrm{unit}}, \lvert\Delta E_0\rvert)\) with a dimensionless tolerance. Here \(I_T\) is the trapezoid integral of \(dV/ds\), \(\Delta E_0\) is the endpoint energy change and \(E_{\mathrm{unit}}\) is one energy unit of the engine. =zero_temperature_tol= is =Option<f64>=. =None=, the default, uses \(2 (\pi^2 / 12) / (\text{planes} - 1)^2\), about 2.6% at 9 planes, and scales when =planes= changes. =with_zero_temperature_tol= sets a value used at every plane count, including a value equal to the 9-plane tolerance. A sharper path can require a larger explicit tolerance. A failing check returns =FluxError::InvalidConfig= before any sampling.
- *Statistical error*: Set =with_target_error(0.01)= and =with_max_rounds(8)= to repeat sampling in rounds of =sample_steps= until =barrier_error= reaches the target. Reaching =max_rounds= first is not an error, so compare =barrier_error= with the target yourself.
- *Reproducibility*: The seed of plane \(k\) in round \(r\) is =seed + 4099 * k + 1000003 * r=, so a fixed =with_seed= gives the same profile for a deterministic engine.
- *Thermostat*: The engine needs a supported canonical thermostat. White noise requires \(\gamma > 0\); its \(\gamma = 0\) NVE mode returns =FluxError::InvalidConfig=. A supported colored-noise thermostat can remain canonical at \(\gamma = 0\). Any canonical setting targets the same profile, so choose the thermostat parameters for the standard error and the burn-in.
- *Engine*: =pafi_profile_dyn= accepts =&mut dyn DynamicsEngine=. The engine is restored on return, with the stochastic stream the only exception.

* Shoot Bennett-Chandler reactive-flux trajectories and compare with Kramers

Combine =hyperplane::sample_hyperplane= (to harvest thermalized configurations on the dividing surface \(x = 0\)) with =kappa::bennett_chandler::shoot_bennett_chandler= and compare the resulting plateau transmission coefficient against =kappa::kramers_transmission_coefficient= @@rst::cite:`goswamiEfficientExploration2025,bennettMolecularDynamics1977,chandlerStatisticalMechanics1978,kramersBrownianMotion1940`@@:

#+begin_src rust
use ndarray::{Array1, ArrayView1};
use rgflux::engine::native::{NativeConfig, NativeEngine};
use rgflux::engine::{HyperplaneConstraint, ThermostatConfig};
use rgflux::hyperplane::{HyperplaneConfig, sample_hyperplane};
use rgflux::kappa::bennett_chandler::{
    KappaConfig, ShootingConfig, shoot_bennett_chandler,
};
use rgflux::kappa::kramers_transmission_coefficient;

struct SeparableDoubleWell2D;

impl rgsaddle::PointSurface for SeparableDoubleWell2D {
    fn eval(&self, r: ArrayView1<f64>) -> Result<(f64, Array1<f64>), rgsaddle::SaddleError> {
        let (x, y) = (r[0], r[1]);
        let dx = x * x - 1.0;
        Ok((dx * dx + y * y, Array1::from_vec(vec![4.0 * x * dx, 2.0 * y])))
    }
}

fn main() -> Result<(), rgflux::FluxError> {
    let gamma = 6.0;
    let omega_b = 2.0;
    let kramers = kramers_transmission_coefficient(gamma, omega_b)?;

    let dividing_surface =
        HyperplaneConstraint::new(Array1::from_vec(vec![1.0, 0.0]), 0.0)?;
    let mut engine = NativeEngine::new(
        SeparableDoubleWell2D,
        NativeConfig::default()
            .with_masses(Array1::from_vec(vec![1.0, 1.0]))
            .with_thermostat(
                ThermostatConfig::default()
                    .with_gamma(gamma)
                    .with_temperature(0.08),
            )
            .with_seed(42),
    )?;

    let surface_sample = sample_hyperplane(
        &mut engine,
        &dividing_surface,
        &HyperplaneConfig::default()
            .with_burn_in_steps(100)
            .with_sample_steps(400)
            .with_retention_stride(10)
            .with_time_step(0.02)
            .with_seed(42),
    )?;

    let shoot_cfg = ShootingConfig::default()
        .with_steps(120)
        .with_time_step(0.05)
        .with_antithetic(true)
        .with_kappa(
            KappaConfig::default()
                .with_commit_checkpoints(64)
                .with_commitment_distance(0.25),
        )
        .with_seed(99);
    let bc = shoot_bennett_chandler(
        &mut engine,
        &dividing_surface,
        surface_sample.configurations.view(),
        &shoot_cfg,
    )?;

    assert!(bc.plateau > 0.0 && bc.standard_error > 0.0);
    assert!(kramers > 0.3 && kramers < 0.31);
    Ok(())
}
#+end_src

The default integrates every half to =steps=. This example opts into early commitment only after specifying both parts of the criterion: =commit_checkpoints = 64= requires 64 consecutive steps (\(64 \times 0.05 = 3.2 > 1 / \lambda_+ \approx 1.65\)), while =commitment_distance = 0.25= requires every counted point to lie at least 0.25 length units from the dividing surface on the same side. Choose the distance inside a physically characterized basin and the window beyond its recrossing time. If either condition is uncertain, keep the default fixed-length shooting: even a long, deep excursion can return, and early commitment would hide that return.

* Sample a temperature range with multithermal OPES and reweight frames

Multithermal OPES @@rst::cite:`invernizziUnifiedApproach2020,invernizziRethinkingMetadynamics2020`@@ biases the potential energy \(U\) so that one run at the thermostat temperature \(T_0\) samples every canonical ensemble between \(T_{\min}\) and \(T_{\max}\). It is the method PLUMED provides as =OPES_EXPANDED= over =ECV_MULTITHERMAL= @@rst::cite:`tribelloPlumed2014,plumedConsortium2019`@@, with the same defaults and the same state file. The method and its equations are under /Multithermal OPES/ in the explanation page.

1. Build an =opes::OpesMultithermal= from an =OpesMultithermalConfig= and the engine =ThermostatConfig=, which supplies \(k_{\mathrm{B}}\) and, unless =temperature= is set, \(T_0\). Give the range with =OpesMultithermalConfig::range=, fix the count with =with_temp_steps= or leave it =None= to estimate it from the =observation_steps= unbiased samples, or list the temperatures with =OpesMultithermalConfig::set_all=.
2. Share it with =SharedOpesMultithermal::new=, wrap the unbiased surface in =OpesMultithermalSurface=, and build the engine over that surface.
3. Call =run_opes_multithermal= with an =OpesRunConfig=. Every =frame_stride= steps it stores the unbiased energy \(U_t\), the bias in force \(V_t\), the force factor \(1 + dV/dU\), and the positions.
4. Read =OpesTrajectory::delta_f= for \(\Delta F(T_k)\), and call =OpesTrajectory::weights= with any target temperature in \([T_{\min}, T_{\max}]\). The returned =Vec<f64>= sums to one and has one entry per stored frame, so it can be passed as =&[f64]= to downstream covariance, clustering, or Markov state model code. A target outside the range returns =FluxError::InvalidConfig=.

The frame weights are

\[
w_t(T) = \frac{\exp\bigl(\beta_0 V_t + (\beta_0 - \beta) U_t\bigr)}{\sum_s \exp\bigl(\beta_0 V_s + (\beta_0 - \beta) U_s\bigr)}, \qquad \beta = \frac{1}{k_{\mathrm{B}} T},
\]

the product of the PLUMED =REWEIGHT_BIAS= and =REWEIGHT_TEMP_PRESS= weights. =MultithermalReweighting::average= returns the weighted mean of an observable with a batch-means standard error and the Kish effective sample size \((\sum_t w_t)^2 / \sum_t w_t^2\) @@rst::cite:`kishSurveySampling1965`@@. Discard an initial stretch of frames by building =MultithermalReweighting::from_bias= over a slice of the stored energies and biases.

The example samples the 2D double well \(U = (x^2 - 1)^2 + y^2/2\) at \(T_0 = 0.3\) over \([0.3, 1.2]\) and reweights the frames to \(T = 0.8\). There \(\langle y^2 \rangle = k_{\mathrm{B}} T\) exactly, because \(y\) is a harmonic coordinate.

#+begin_src rust
use ndarray::{Array1, ArrayView1};
use rgflux::engine::native::{NativeConfig, NativeEngine};
use rgflux::engine::{DynamicsEngine, ThermostatConfig};
use rgflux::opes::{
    OpesMultithermal, OpesMultithermalConfig, OpesMultithermalSurface, OpesRunConfig,
    SharedOpesMultithermal, run_opes_multithermal,
};

struct DoubleWell2D;

impl rgsaddle::PointSurface for DoubleWell2D {
    fn eval(&self, r: ArrayView1<f64>) -> Result<(f64, Array1<f64>), rgsaddle::SaddleError> {
        let a = r[0] * r[0] - 1.0;
        Ok((
            a * a + 0.5 * r[1] * r[1],
            Array1::from_vec(vec![4.0 * r[0] * a, r[1]]),
        ))
    }
}

/// Weighted covariance of two per-frame features, as downstream code takes it.
fn weighted_covariance(weights: &[f64], a: &[f64], b: &[f64]) -> f64 {
    let mean = |v: &[f64]| weights.iter().zip(v).map(|(w, x)| w * x).sum::<f64>();
    let (ma, mb) = (mean(a), mean(b));
    weights
        .iter()
        .zip(a.iter().zip(b))
        .map(|(w, (x, y))| w * (x - ma) * (y - mb))
        .sum()
}

fn main() -> Result<(), rgflux::FluxError> {
    let thermostat = ThermostatConfig::default()
        .with_temperature(0.3)
        .with_gamma(1.0);
    let config = OpesMultithermalConfig::range(0.3, 1.2)
        .with_temp_steps(6)
        .with_pace(50);
    let shared = SharedOpesMultithermal::new(OpesMultithermal::new(config, &thermostat)?);
    let surface = OpesMultithermalSurface::new(DoubleWell2D, shared.clone());
    let mut engine = NativeEngine::new(
        surface,
        NativeConfig::default()
            .with_masses(Array1::from_vec(vec![1.0, 1.0]))
            .with_thermostat(thermostat)
            .with_seed(11),
    )?;
    engine.set_positions(Array1::from_vec(vec![-1.0, 0.0]).view())?;
    engine.shoot_velocities(11)?;

    let run = OpesRunConfig::default()
        .with_steps(1_000_000)
        .with_time_step(0.01)
        .with_frame_stride(50);
    let trajectory = run_opes_multithermal(&mut engine, &shared, &run)?;
    assert_eq!(trajectory.temperatures().len(), 6);
    assert_eq!(trajectory.delta_f().len(), 6);

    let weights: Vec<f64> = trajectory.weights(0.8)?;
    assert_eq!(weights.len(), trajectory.positions.len());
    let y: Vec<f64> = trajectory.positions.iter().map(|p| p[1]).collect();
    let y_variance = weighted_covariance(&weights, &y, &y);
    assert!((y_variance - 0.8).abs() < 0.05, "<y^2> = {y_variance}");
    assert!(trajectory.weights(1.5).is_err());
    Ok(())
}
#+end_src

To continue a run, write =OpesMultithermal::write_state= at the end of one segment and rebuild the bias with =OpesMultithermal::from_state= and the same configuration and thermostat. The file has the layout of the PLUMED =STATE_WFILE=, with the temperature column named =ecv.ene=, so PLUMED can restart from an =rgflux= state and =rgflux= can restart from a PLUMED state.

The restart keeps the update cadence and the thermodynamic reference:

- The bias absorbs a sample only at MD steps that are multiples of =pace=, counted from step 0, so a continuation must keep the absolute step. The state records the last step the bias saw, =from_state= restores it as =OpesMultithermal::last_step=, and =run_opes_multithermal= with the default =OpesRunConfig::start_step= of =None= continues from it. An explicit =start_step= that differs from the restored step returns =FluxError::InvalidConfig= before any step is integrated, and so does an update at an earlier step. The configuration at the restored step is not absorbed a second time.
- \(\Delta F\) and =rct= are free energies at \(T_0\) in units of \(k_{\mathrm{B}}\), so they do not carry over to another \(T_0\), \(k_{\mathrm{B}}\), or ladder. The state records \(T_0\), \(k_{\mathrm{B}}\), and the reweighting range \((T_{\min}, T_{\max})\) at full precision, and =from_state= returns =FluxError::InvalidConfig= when the configuration and thermostat differ from them beyond a relative \(64\varepsilon\), or when only some of the entries are present.

These entries are comment lines of the form =# rgflux temperature 3e-1=, which PLUMED skips, so the file stays a valid PLUMED state. A state written by PLUMED has none of them: =from_state= then checks only the six-digit temperature labels, the caller must keep \(T_0\) and \(k_{\mathrm{B}}\) unchanged, and =run_opes_multithermal= requires an explicit =start_step=, since =last_step= is =None=.

#+begin_src rust
use ndarray::{Array1, ArrayView1};
use rgflux::FluxError;
use rgflux::engine::native::{NativeConfig, NativeEngine};
use rgflux::engine::{DynamicsEngine, ThermostatConfig};
use rgflux::opes::{
    OpesMultithermal, OpesMultithermalConfig, OpesMultithermalSurface, OpesRunConfig,
    SharedOpesMultithermal, run_opes_multithermal,
};

struct DoubleWell;

impl rgsaddle::PointSurface for DoubleWell {
    fn eval(&self, x: ArrayView1<f64>) -> Result<(f64, Array1<f64>), rgsaddle::SaddleError> {
        let a = x[0] * x[0] - 1.0;
        Ok((a * a, Array1::from_vec(vec![4.0 * x[0] * a])))
    }
}

fn main() -> Result<(), rgflux::FluxError> {
    let thermostat = ThermostatConfig::default().with_temperature(0.3);
    let config = OpesMultithermalConfig::range(0.3, 1.0)
        .with_temp_steps(4)
        .with_pace(10)
        .with_observation_steps(10);
    let shared = SharedOpesMultithermal::new(OpesMultithermal::new(config.clone(), &thermostat)?);
    let surface = OpesMultithermalSurface::new(DoubleWell, shared.clone());
    let native = NativeConfig::default()
        .with_thermostat(thermostat)
        .with_seed(3);
    let mut engine = NativeEngine::new(surface, native)?;
    engine.set_positions(Array1::from_vec(vec![-1.0]).view())?;
    let run = OpesRunConfig::default().with_steps(1_005).with_time_step(0.01);
    let first = run_opes_multithermal(&mut engine, &shared, &run)?;

    let mut state = Vec::new();
    first.bias.write_state(&mut state, 1_005.0 * 0.01)?;

    // Same configuration and thermostat; `start_step` stays `None`, so the
    // second segment continues at the stored step 1005.
    let restored = OpesMultithermal::from_state(config.clone(), &thermostat, &state[..])?;
    assert_eq!(restored.last_step(), Some(1_005));
    shared.with_bias_mut(|bias| *bias = restored)?;
    let second = run_opes_multithermal(&mut engine, &shared, &run)?;
    assert_eq!(second.steps[0], 1_005);
    assert_eq!(second.last_step, 2_010);

    // Restarting the step count or changing T0 is refused.
    let shifted = run.clone().with_start_step(0);
    assert!(matches!(
        run_opes_multithermal(&mut engine, &shared, &shifted),
        Err(FluxError::InvalidConfig(_))
    ));
    let warmer = thermostat.with_temperature(0.4);
    assert!(matches!(
        OpesMultithermal::from_state(config, &warmer, &state[..]),
        Err(FluxError::InvalidConfig(_))
    ));
    Ok(())
}
#+end_src

* Wrap an =rgmin= objective with =EindirSurface=

Any =eindir_core::DifferentiableObjective<f64>= (such as =rgmin::Oracle=) can be adapted into a =ForceSurface= via =engine::EindirSurface= and passed to =NativeEngine=:

#+begin_src rust
use ndarray::Array1;
use rgflux::engine::native::{NativeConfig, NativeEngine};
use rgflux::engine::{DynamicsEngine, EindirSurface};

fn main() -> Result<(), rgflux::FluxError> {
    let oracle = rgmin::Oracle::unbounded(2, |x| {
        let energy = 0.5 * (x[0] * x[0] + 4.0 * x[1] * x[1]);
        let grad = Array1::from_vec(vec![x[0], 4.0 * x[1]]);
        (energy, grad)
    });
    let surface = EindirSurface::new(oracle);
    let mut engine = NativeEngine::new(
        surface,
        NativeConfig::default()
            .with_masses(Array1::from_vec(vec![1.0, 2.0]))
            .with_seed(7),
    )?;
    engine.shoot_velocities(7)?;
    let report = engine.step(0.01)?;
    assert!(report.potential_energy.is_finite() && report.kinetic_energy.is_finite());
    Ok(())
}
#+end_src
