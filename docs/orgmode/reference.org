* Module overview

| Module | Scope | Status |
|---+---+---|
| =engine= | =DynamicsEngine= trait, =ForceSurface=, =EindirSurface=, =HyperplaneConstraint=, =ThermostatConfig=, =SurfaceVelocityPolicy=, =StepReport=, =native= BAOAB/RATTLE backend, optional direct =lammpc= backend, =rgpot= static PES wrapper, and =rgpot-session= MD session skeleton (=openmm=, =nblib=, =lammps=) | Implemented (=native=, =lammpc=, =rgpot=) and =rgpot-session= skeleton |
| =stats= | Batch means, effective sample size =n_eff=, and stationarity diagnostics | Implemented; spline-propagated profile covariance helpers are not yet implemented |
| =kappa::bennett_chandler= | Engine-free reactive-flux estimator and =DynamicsEngine= trajectory shooter | Implemented |
| =kappa= | Kramers analytical barrier-recrossing factor; surface-shooting quench classifiers and first-crossing estimators | =kramers_transmission_coefficient= and =KappaConfig= implemented; the quench and first-crossing drivers are not yet implemented |
| =hyperplane= | Constrained hyperplane sampling (=sample_hyperplane=) and zero-variance control variates | Mean constraint force and configuration retention implemented; the in-plane virial, torque, and control variates are not yet implemented |
| =pafi= | Projected Average Force Integration along reaction paths (=PafiConfig=, =FreeEnergyProfile=, =pafi_profile=, =pafi_profile_dyn=) | Implemented: mass-metric spline planes with not-a-knot ends, zero-temperature trapezoid path-force check, burn-in and batch-means sampling per plane, adaptive rounds to a target error, cubic Hermite free-energy profile, global interpolant maximum, projected-frequency reactant partition, barrier, and normalized rate with propagated errors; the engine is restored on return |
| =ohtst= | OH-TST with a fixed hyperplane normal (=optimize_hyperplane=) | Implemented for a fixed normal with =rgsaddle::flux_mass=; normal optimization is not yet implemented |
| =ffs= | Forward Flux Sampling across ordered interfaces (=forward_flux_rate=) | Implemented: flux collection, staged trials, and uncertainty propagation. Exit restores positions, velocities, the periodic cell, the thermostat, and the constraint; the stochastic stream is left where the run put it |
| =network= | Symmetry-resolved rate networks and kinetic Monte Carlo rate tables (=NetworkConfig=, =RateTableConfig=, =RateEdge=, =build_rate_table=) | =RateEdge::new= and configuration types implemented; =build_rate_table= is not yet implemented |
| =error= | Shared =FluxError= enum and =From<rgsaddle::SaddleError>= conversion | Implemented |

** =pafi::PafiConfig=

| Field | Type | Default | Constraint / Meaning |
|---+---+---+---|
| =planes= | =usize= | =9= | Number of hyperplanes at equal spacing along the spline path (\(\ge 2\)) |
| =burn_in_steps= | =usize= | =500= | Equilibration steps discarded on each hyperplane before sampling (\(\ge 1\)); every plane and round restarts from the anchor |
| =sample_steps= | =usize= | =4_000= | Production steps added per hyperplane and round (\(\ge 2\)) |
| =time_step= | =f64= | =0.002= | Integration timestep \(\Delta t > 0\) in engine time units |
| =target_error= | =Option<f64>= | =None= | Optional target standard error on \(\Delta F\) (finite, \(\ge 0\)); =None= runs one round |
| =max_rounds= | =usize= | =4= | Maximum sampling rounds (\(\ge 1\)); later rounds run only while =target_error= is set and not reached, and missing it is not an error |
| =zero_temperature_tol= | =f64= | \(2 (\pi^2 / 12) / 8^2 \approx 0.0257\) | Dimensionless tolerance for \(\lvert I_T - \Delta E_0\rvert / \max(E_{\mathrm{unit}}, \lvert\Delta E_0\rvert)\), where both energies use engine energy units and \(E_{\mathrm{unit}}\) is one such unit (finite, \(\ge 0\)); see the scaling note below |
| =seed= | =u64= | =1= | Base of the per-plane seeds =seed + 4099 * plane + 1000003 * round= (wrapping) |
| =stats= | =StatsConfig= | =StatsConfig::default()= | Batch-means settings for the per-plane force series |

Here \(I_T\) is the trapezoid integral of \(dV/ds\) over the plane anchors and \(\Delta E_0\) is the endpoint energy change. The ratio is relative to \(\lvert\Delta E_0\rvert\) at or above one engine energy unit and bounds the absolute discrepancy below that scale.

The value stored by =PafiConfig::default()= is the 9-plane value shown in the table. While the field retains that value, the effective tolerance is \(2 (\pi^2 / 12) / (\text{planes} - 1)^2\), so changing =planes= scales the tolerance with the trapezoid error. An explicitly different value is used unchanged. The scaling follows a quarter-turn circular arc through a harmonic well. A path that turns further can need a larger explicit tolerance.

** =pafi::FreeEnergyProfile=

| Field | Type | Meaning |
|---+---+---|
| =arc_lengths= | =Vec<f64>= | Plane coordinates \(s_k\): the mass-weighted chord-length parameter of the spline, from 0 at the first image to the total path length at the last, at equal spacing. Not scaled to \([0, 1]\) |
| =free_energy= | =Vec<f64>= | \(F(s_k) - F(s_0)\) by cubic Hermite quadrature of the plane means; the first entry is 0. With four or more planes it is exact for a cubic gradient |
| =standard_error= | =Vec<f64>= | Standard error of =free_energy=: batch-means plane-force error through the Hermite weights, combined by hypot with the absolute Hermite-minus-trapezoid difference on the same nodes; the first entry is 0. | =barrier= | =f64= | \(\Delta F\), the global maximum of the Hermite interpolant, which can exceed every sampled value |
| =barrier_error= | =f64= | Standard error of =barrier=: the same combination at =s*= |
| =dividing_index= | =usize= | First plane with the highest sampled free energy. The interpolant maximum recorded in =dividing_arc= can lie on a different interval |
| =dividing_arc= | =f64= | Arc length \(s^*\) of the global maximum of the Hermite interpolant |
| =reactant_frequency= | =f64= | \(\omega_0 = ( \mathbf{n}^\top \mathbf{H}^{-1} \mathbf{n} )^{-1/2}\) from the mass-weighted Hessian at the first image, in inverse engine time |

| =reactant_log_partition= | =f64= | \(\ln Z_R = \tfrac{1}{2}\ln(2\pi k_{\mathrm{B}}T) - \ln \omega_0\) |
| =normalized_rate= | =Option<f64>= | \(k = (\omega_0 / 2\pi) \exp(-\Delta F / k_{\mathrm{B}}T)\) in inverse engine time. =Some= when its exponential is finite and positive; otherwise =None= |

| =quadrature_residual= | =f64= | Largest absolute gap between the Hermite integral of \(dV/ds\) and the endpoint energy change. The acceptance check remains the trapezoid comparison in =PafiConfig::zero_temperature_tol= |
