Every public configuration struct is =#[non_exhaustive]= and provides chainable =#[must_use]= =with_*= builder methods. Setter methods for =Option<T>= fields accept =impl Into<Option<T>>= so passing a bare =T= sets =Some(T)= and passing =None= clears the option.

** =pafi::PafiConfig=

| Field | Type | Default | Constraint / Meaning |
|---+---+---+---|
| =planes= | =usize= | =9= | Number of hyperplanes at equal spacing along the spline path (\(\ge 2\)) |
| =burn_in_steps= | =usize= | =500= | Equilibration steps discarded on each hyperplane before sampling (\(\ge 1\)); every plane and round restarts from the anchor |
| =sample_steps= | =usize= | =4_000= | Production steps added per hyperplane and round (\(\ge 2\)) |
| =time_step= | =f64= | =0.002= | Integration timestep \(\Delta t > 0\) in engine time units |
| =target_error= | =Option<f64>= | =None= | Optional target standard error on \(\Delta F\) (finite, \(\ge 0\)); =None= runs one round |
| =max_rounds= | =usize= | =4= | Maximum sampling rounds (\(\ge 1\)); later rounds run only while =target_error= is set and not reached, and missing it is not an error |
| =zero_temperature_tol= | =Option<f64>= | =None= | Dimensionless tolerance for \(\lvert I_T - \Delta E_0\rvert / \max(E_{\mathrm{unit}}, \lvert\Delta E_0\rvert)\), where both energies use engine energy units and \(E_{\mathrm{unit}}\) is one such unit. =None= uses \(2 (\pi^2 / 12) / (\text{planes} - 1)^2\) (\(\approx 0.0257\) at 9 planes). =Some(value)= uses that finite value (\(\ge 0\)) at every plane count, including the 9-plane value; see the scaling note below |
| =seed= | =u64= | =1= | Base of the per-plane seeds =seed + 4099 * plane + 1000003 * round= (wrapping) |
| =stats= | =StatsConfig= | =StatsConfig::default()= | Batch-means settings for the per-plane force series |

Here \(I_T\) is the trapezoid integral of \(dV/ds\) over the plane anchors and \(\Delta E_0\) is the endpoint energy change. The ratio is relative to \(\lvert\Delta E_0\rvert\) at or above one engine energy unit and bounds the absolute discrepancy below that scale.

=PafiConfig::default()= leaves =zero_temperature_tol= set to =None=. While it is =None=, the effective tolerance is \(2 (\pi^2 / 12) / (\text{planes} - 1)^2\), so changing =planes= scales the tolerance with the trapezoid error (\(\approx 0.0257\) at the default 9 planes). Setting an explicit value via =with_zero_temperature_tol(tol)= (or =Some(tol)=) fixes that tolerance unchanged across plane counts; passing =None= restores the automatic scaling. The scaling follows a quarter-turn circular arc through a harmonic well. A path that turns further can need a larger explicit tolerance.

** =pafi::FreeEnergyProfile=

| Field | Type | Meaning |
|---+---+---|
| =arc_lengths= | =Vec<f64>= | Plane coordinates \(s_k\): the mass-weighted chord-length parameter of the spline, from 0 at the first image to the total path length at the last, at equal spacing. Not scaled to \([0, 1]\) |
| =free_energy= | =Vec<f64>= | \(F(s_k) - F(s_0)\) by cubic Hermite quadrature of the plane means; the first entry is 0. With two planes the derivative correction cancels and the rule is the trapezoid rule. With three planes it is exact for a quadratic gradient. With four or more planes it is exact for a cubic gradient |
| =standard_error= | =Vec<f64>= | Standard error of =free_energy=: batch-means plane-force error through the Hermite weights, combined by hypot with the absolute Hermite-minus-trapezoid difference on the same nodes; the first entry is 0. The weighted uncertainty norm is scaled to avoid overflow from finite plane errors |
| =barrier= | =f64= | \(\Delta F\), the global maximum of the Hermite interpolant, which can exceed every sampled value |
| =barrier_error= | =f64= | Standard error of =barrier=: the same combination at =s*= |
| =dividing_index= | =usize= | First plane with the highest sampled free energy. The interpolant maximum recorded in =dividing_arc= can lie on a different interval |
| =dividing_arc= | =f64= | Arc length \(s^*\) of the global maximum of the Hermite interpolant |
| =reactant_frequency= | =f64= | \(\omega_0 = ( \mathbf{n}^\top \mathbf{H}^{-1} \mathbf{n} )^{-1/2}\) from the mass-weighted Hessian at the first image, in inverse engine time (positive definiteness off the zero modes is certified by a dense eigensolver when \(\text{dof} \le 128\)) |
| =reactant_hessian_certified= | =bool= | =true= when the full reactant Hessian was certified positive definite off the zero modes by the dense eigensolver; =false= above 128 coordinates, where dense certification is skipped while finite forces and positive projected curvature remain required |
| =reactant_partition= | =Option<f64>= | Linear reactant partition function \(Z_R = \exp(\ln Z_R)\) in units of \(s\), or =None= if \(\exp(\ln Z_R)\) overflows or underflows =f64= (never =Some(0.0)=) |
| =reactant_log_partition= | =f64= | \(\ln Z_R\) from the doubled-trapezoid integral \(Z_R = 2\int_0^{s_{\mathrm{end}}} \exp(-(F(s) - F(s_0)) / k_{\mathrm{B}}T)\,ds\) in log space, where \(s_{\mathrm{end}} = s_k\) when \(s^* = s_k\) and \(s_{\mathrm{end}} = s_{k+1}\) when \(s^*\) is interior to \([s_k, s_{k+1}]\) |
| =normalized_rate= | =Option<f64>= | Linear transition rate \(k = \exp(\ln k)\) in inverse engine time, or =None= if \(\exp(\ln k)\) overflows or underflows =f64= (never =Some(0.0)=) |
| =normalized_log_rate= | =f64= | \(\ln k = \tfrac{1}{2}\ln(k_{\mathrm{B}}T / 2\pi) - \Delta F / k_{\mathrm{B}}T - \ln Z_R\), finite even when =normalized_rate= underflows or overflows =f64= |
| =normalized_rate_error= | =Option<f64>= | Delta-method standard error \(\exp(\ln k + \ln \sigma_{\ln k})\) propagating the plane-mean errors through both \(\Delta F / k_{\mathrm{B}}T\) and \(\ln Z_R\) in log space, or =None= if the linear error overflows =f64= (=Some(0.0)= when \(\sigma_{\ln k} = 0\) or the product underflows) |
| =quadrature_residual= | =f64= | Largest absolute gap between the Hermite integral of \(dV/ds\) and the endpoint energy change. The acceptance check remains the trapezoid comparison in =PafiConfig::zero_temperature_tol= |
