* Configuration structs and field defaults

Every public configuration struct is =#[non_exhaustive]= and provides chainable =#[must_use]= =with_*= builder methods. Setter methods for =Option<T>= fields accept =impl Into<Option<T>>= so passing a bare =T= sets =Some(T)= and passing =None= clears the option.

| =reactant_fmax= | =f64= | =1e-6= | Physical force tolerance on the reactant minimum and on the seed-plane normal slope, finite and \(> 0\), in the engine force unit (eV/Å in metal units). The reactant is a minimum once \(\max_i \lvert F_i \rvert\) is at most this value, and the seed plane is kept verbatim when \(\lvert -\mathbf{n} \cdot \mathbf{F} \rvert\) is at most this value above the minimum. The default is the gradient tolerance of =rgmin::Lbfgs::default()= on the same infinity norm; a non-finite or non-positive value returns =FluxError::InvalidConfig= |

A reactant located to =reactant_fmax= lies about \(\varepsilon = \text{reactant\_fmax} / \kappa\) from the exact minimum. The curvature inferred over a probe of length \(\delta\) then moves by a relative \(\varepsilon / \delta\) and the barrier by about \(\kappa \varepsilon^2 / 2\). At the default and \(\kappa = 1\) eV/Å², \(\delta = 0.25\) Å, these are \(4 \times 10^{-6}\) and \(5 \times 10^{-13}\) eV. Neither force criterion uses =stats::SERIES_FLAT_TOL=: forces at a relaxed minimum or saddle carry rounding noise that grows with the atom count, the total energy, and the coordinate magnitude. =SERIES_FLAT_TOL= remains the relative tolerance of the bisection bracket width.

** =pafi::PafiConfig=

| Field | Type | Default | Constraint / Meaning |
|---+---+---+---|
| =planes= | =usize= | =9= | Number of hyperplanes at equal spacing along the spline path (\(\ge 2\)) |
| =burn_in_steps= | =usize= | =500= | Equilibration steps discarded on each hyperplane before sampling (\(\ge 1\)); every plane and round restarts from the anchor |
| =sample_steps= | =usize= | =4_000= | Production steps added per hyperplane and round (\(\ge 2\)) |
| =time_step= | =f64= | =0.002= | Integration timestep \(\Delta t > 0\) in engine time units |
| =target_error= | =Option<f64>= | =None= | Optional target standard error on \(\Delta F\) (finite, \(\ge 0\)); =None= runs one round |
| =max_rounds= | =usize= | =4= | Maximum sampling rounds (\(\ge 1\)); later rounds run only while =target_error= is set and not reached, and missing it is not an error |
| =zero_temperature_tol= | =Option<f64>= | =None= | Dimensionless tolerance for \(\lvert I_T - \Delta E_0\rvert / \max(E_{\mathrm{unit}}, \lvert\Delta E_0\rvert)\), where both energies use engine energy units and \(E_{\mathrm{unit}}\) is one such unit. =None= uses \(2 (\pi^2 / 12) / (\text{planes} - 1)^2\) (\(\approx 0.0257\) at 9 planes). =Some(value)= uses that finite value (\(\ge 0\)) at every plane count, including the 9-plane value; see the scaling note below |
| =seed= | =u64= | =1= | Base of the per-plane seeds =seed + 4099 * plane + 1000003 * round= (wrapping) |
| =stats= | =StatsConfig= | =StatsConfig::default()= | Batch-means settings for the per-plane force series |

Here \(I_T\) is the trapezoid integral of \(dV/ds\) over the plane anchors and \(\Delta E_0\) is the endpoint energy change. The ratio is relative to \(\lvert\Delta E_0\rvert\) at or above one engine energy unit and bounds the absolute discrepancy below that scale.

=None=, the value stored by =PafiConfig::default()=, sets the effective tolerance to \(2 (\pi^2 / 12) / (\text{planes} - 1)^2\). At the default 9 planes that is the \(\approx 0.0257\) in the table, and changing =planes= scales the tolerance with the trapezoid error. =Some(value)= uses =value= at every plane count, including a value equal to the 9-plane tolerance. The scaling follows a quarter-turn circular arc through a harmonic well. A path that turns further can need a larger explicit tolerance.
