* String method API

=finite_temperature_string= accepts any mutable =DynamicsEngine=, an =(images, dof)= array, and =FiniteTemperatureStringConfig=. Its result contains final images and the projected forces, sampled positions, and position covariances collected immediately before the last image update and reparametrization. =swarm_string= accepts =SwarmStringConfig= and reports final images and mean swarm displacements collected before its final update and reparametrization. Both configuration structs are =#[non_exhaustive]=, implement =Default=, and provide chainable =with_*= builders.

The current implementation uses non-periodic equal-chord redistribution through the public =rgsaddle::reparametrize= utility. Hyperplane integration itself continues to respect the cell owned by the dynamics engine.
